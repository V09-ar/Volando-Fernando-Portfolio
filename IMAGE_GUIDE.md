# Image Guide

The following supplied assets have been placed in the portfolio:

- `assets/images/profile.jpg` — profile photograph used in the hero.
- `assets/images/projects/sweatsmart-ai.png` — supplied SweatSmart AI interface screenshot.
- `assets/images/projects/printx-global.png` — supplied PrintX Global website screenshot.

Add these only when verified source images are available:

- `assets/images/graduation.jpg` — graduation photograph.
- `assets/images/university.jpg` — University of West London or American National College image.
- `assets/images/achievements.jpg` — verified academic achievement image.
- `assets/images/projects/mycloth.png` — MyCloth website screenshot.
- `assets/images/projects/fabric-research.png` — original research visual or approved project image.
- `assets/images/projects/powerbi.png` — Power BI dashboard screenshot.
- `assets/images/certificates/azure-ai.png`, `azure-foundry.png`, `data-analysis.png`, `powerbi.png` — certificate images, if available.
- `assets/documents/Volando-Fernando-CV.pdf` — verified public CV for the download buttons.

The current site intentionally uses design placeholders for missing project visuals rather than unverified imagery.
